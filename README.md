# LeetCode Student Tracker

A full-stack web application to track student progress on LeetCode.

## Folder Structure
- `backend/`: Node.js + Express server.
- `frontend/`: React + Vite + Tailwind CSS 4.0 frontend.

## Installation

### Backend
1. `cd backend`
2. `npm install`
3. `node server.js`

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev`

## API Endpoints
- `GET /check/:username`: Returns solving status for predefined problems.
